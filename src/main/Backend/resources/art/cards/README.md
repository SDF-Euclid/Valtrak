# Card art

Put a card's real picture here and the client uses it instead of the generated placeholder.

- **File name:** the card's name in lower case, with every run of characters that aren't letters or digits replaced by one dash.
  For example `Leopard 2A7V` -> `leopard-2a7v.png`, `Sho't Kal` -> `sho-t-kal.png`, `5x 120mm HEAT Crate` -> `5x-120mm-heat-crate.png`.
- **Format:** PNG (or JPG). The picture area is 155 x 90 (about 16:9), so use a wide image; 620 x 360 or larger looks sharp.
  Pictures of other shapes are scaled to fill the area and centred, so the edges may be cropped.
- Cards without a picture keep their generated placeholder, so art can be added a few cards at a time.
